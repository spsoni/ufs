# Configuring S3

## Bring your own client

Each S3 object creates `boto3.client("s3")` lazily the first time it talks to S3. To control
credentials, region, retries or the endpoint, pass a client:

```python
import boto3
from ufs import FS

session = boto3.Session(profile_name="analytics")
client = session.client("s3", region_name="eu-west-1")

data = FS.to_directory("s3://my-bucket/data", s3_client=client)
```

Objects derived from `data` (`join_as_file`, `parent`, `list_file_objects`, `glob`, `/`, ...)
reuse the same client.

## S3-compatible storage

Any service that speaks the S3 API works, for example MinIO, Cloudflare R2, Ceph or LocalStack:

```python
client = boto3.client(
    "s3",
    endpoint_url="http://localhost:9000",
    aws_access_key_id="minio",
    aws_secret_access_key="minio123",
)
```

## `s3://` and `s3a://`

Hadoop and Spark use `s3a://`. `ufs` accepts both and normalises to `s3://` by default. To
produce `s3a://` paths (for example, to hand back to Spark), use:

```python
from ufs import S3Directory

d = S3Directory("s3://bucket/table", protocol="s3a://")
str(d)   # 's3a://bucket/table/'
```

## Logical vs marker directories

By default (`keep_directories_logical=True`) directories exist only implicitly, through
the keys underneath them. With `keep_directories_logical=False`, `create()` writes an empty
`prefix/` marker object, as the AWS console does, so an empty directory can exist:

```python
d = S3Directory("s3://bucket/empty", keep_directories_logical=False)
d.create()
d.exists()       # True
d.list_files()   # [] — markers are never reported as files
```

## Permissions

| Operation | IAM actions |
| --- | --- |
| read, `exists`, `size`, download | `s3:GetObject` |
| list, glob, directory `exists` | `s3:ListBucket` |
| write, upload, `touch` | `s3:PutObject` |
| remove | `s3:DeleteObject` |
| S3→S3 copy | `s3:GetObject` on source, `s3:PutObject` on destination |
